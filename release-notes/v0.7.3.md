# Pi Web Box v0.7.3

本版本新增「等待回答提醒」，并修复了在后台收不到 Pi Web 询问通知的问题。

## 新增

- 等待回答提醒：Pi Web 弹出需要你回答的扩展弹窗时（`ask_user_question` 插件的选择题、以及 select / confirm / input / editor / custom 各类扩展对话框），窗口不在前台会立刻提醒。
  - 窗口可见但未聚焦（含最小化）：闪烁任务栏按钮。
  - 窗口已隐藏到托盘：改为闪烁托盘图标（右上角橙色圆点，每 600 毫秒切换一次），托盘提示与菜单同步显示「有弹窗等待你的回答」。
  - 两种情况都会发送 Windows 系统通知，标题带会话名，正文取问题的首行（选择题附选项个数），点击通知直接打开窗口并切到对应会话。
  - 窗口重新获得焦点即视为已看到，闪烁与提醒立即全部停止。
- Box 设置「外观与行为」新增「等待回答时提醒」开关，默认开启，改完立即生效、无需重启。

## 修复与优化

- 修复在后台收不到询问提醒的问题。根因不在插件：Pi Web 页面自带一条「等待输入 → 桌面通知」逻辑，但它在存在 service worker 注册时优先调用 `ServiceWorkerRegistration.showNotification()`，而 Electron 不支持持久通知（electron#13041），该调用**静默返回成功且不抛错**，导致永远走不到 `new Notification()` 的回退分支，页面这条通道在 Box 里实际一条通知都发不出来。现在改由 Box 主进程发送原生通知，不再依赖页面，并额外补上任务栏与托盘闪烁。
- 提醒只在窗口未聚焦时触发；窗口就在前台时弹窗本身可见，不做任何打扰。同一弹窗重复下发（例如 custom 面板每次重绘）只提醒一次，弹窗关闭、页面重载、标签关闭或切换会话都会撤销提醒。
- `notify`、`setStatus`、`setWidget` 等只做展示的扩展事件不会被误判为「等待输入」。

- TypeScript 类型检查通过，102 项单元测试通过。
- 真实 Electron 回归新增 `scripts/smoke-attention.cjs` 共 6 项：隐藏到托盘闪托盘并发通知、可见未聚焦切任务栏闪烁、重复下发不重复提醒、关闭后停止、`notify/setStatus` 不误报、开关关掉不打扰且重新打开立刻恢复。
- 六标签与消息分页两项既有回归继续通过（通知入库数量、颜色、排序、最小化恢复、分页游标均无变化）。

## 使用说明

- 下载 Windows x64 安装包；安装前请先从托盘退出旧版 Pi Web Box。
- 关闭「等待回答时提醒」后不再闪烁和通知，仅影响提醒，不影响消息中心继续记录。
- 若托盘图标被关闭（设置里「显示托盘图标」），窗口隐藏到托盘时只剩系统通知这一条提醒通道。
- 排查提醒是否触发，可查看 Box 日志中的 `检测到等待回答的弹窗：会话 xxx（select）。` 一行，日志路径在设置窗口与故障页可见。
