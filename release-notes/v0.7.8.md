# Pi Web Box v0.7.8

本版本收尾修复「自动命名仍是坏标题」和「提示词增强仍会回答草稿」的两个残留问题，并让内置扩展随 Box 升级自动更新。

## 修复

- **根因：请求里的 system 规则被网关丢掉**：会话命名与提示词增强都把任务规则放在 system 角色，但 magpie/WorkBuddy 这类第三方网关会丢弃 system 消息，只把 user 正文交给模型，模型于是把「会话记录」或「待改写草稿」当成用户提问直接回答。现在规则同时写进 user 正文开头（对正常遵循 system 的供应商只是无害重复），两条链路都已验证能稳定输出标题/指令。
- **内置扩展自动同步**：启动时检查用户已安装的内置扩展（会话命名、用量记录），发现版本低于安装包内置版本就静默覆盖，并在通知里提示。以后再升级 Box 不需要手动重装插件；`pi-session-name` 会从 1.1.0 直接升到 1.3.0。
- **会话命名**：标题语料现在只取用户消息，助手回复不再参与（只有整场会话没有用户消息时才退回最后一条助手消息），避免「已修复并打包完成，版本 v0.7.7」这类交付话术被抄成标题。
- **截断残片清理**：标题后缀截到 30 字后，会继续清掉尾部半个括号、`-s` 这类单字母残片和悬空标点，不再出现「…没有-s」。
- **自动命名兜底**：模型连续两次给出助手式回答时，不再写「新对话」占位，而是用首条用户目标生成可读标题（最多 20 字）。
- **提示词增强**：新增对「这看起来是…」「从你提供的信息看…」「建议排查方向：1…」这类分析式回答的识别；只要正文是多条建议且直接回应草稿，就判定为回答并重试。提示词里也补了正反例，并给请求加上 `temperature: 0.2`。
- **会话命名提示词**：补充「AGENTS.md-内容与前置提示词梳理」这类正确示例，明确禁止「我没有读取文件的工具」「本会话只挂了…」这类助手自述。

## 验证

- TypeScript 类型检查通过；154 项 Box 单元测试、16 项 `pi-session-name` 扩展测试全部通过。
- 新增回归：真实坏标题「我没有读取文件的工具（本会话…没有-s」被拒绝并清洗为「我没有读取文件的工具」；真实长回答「这看起来是一个会话标题生成的问题…」被判为回答；两次坏标题后回退到首条用户目标。

## 使用说明

- 下载 Windows x64 安装包；安装前请先从托盘退出旧版 Pi Web Box。
- 安装后首次启动会自动把已安装的 `pi-session-name` 更新到 1.3.0，无需再进设置手动重装。若你在 Box 之外单独运行 pi，请重启 pi 或执行一次 `/reload`。
- 本版本由离线单元测试与扩展测试验证，真实模型效果请按实际使用场景测试。
