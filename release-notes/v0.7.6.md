# Pi Web Box v0.7.6

本版本修复 pi-web 0.14/0.15 中文界面下输入框旁的「提示词增强」「生成标题」等按钮整体消失的问题。

## 修复

- **中文界面下重新显示输入区控件**：pi-web 从 0.14 起把模型按钮的 `title` 做了多语言处理，简体中文是「更换模型」、繁体中文是「更換模型」；切换模型、禁用或没有可用模型时，还会变成「正在切换模型」「没有可用模型」或模型名。Box 旧版固定用 `title="Change model"` 寻找输入区，找不到时就把「场景选择 / 增强 / 生成标题 / 回到底部」所在的整个控件隐藏了，因此把界面切成英文后按钮才会回来。
- 现在改用与语言无关的 DOM 结构定位：优先找 `.model-selector` 里的 listbox 按钮，并把控件挂到输入框底部的同一组按钮；模型按钮不渲染时回退到 `.chat-input-controls` 的第一组；最后仍保留英文 `title` 兜底，兼容早期 pi-web。中文、繁体中文、英文以及不同模型状态下均可正常显示，按钮位置与功能和之前一致。

## 验证

- TypeScript 类型检查通过；141 项单元测试通过（新增中文/繁中/切换中/无模型/旧版英文 `title` 的锚点归位与未挂载时隐藏用例）。
- 真实 Electron 回归中的模拟页面已改为 pi-web 0.15 的中文输入区结构（`.chat-input-controls` + `.model-selector` + `aria-haspopup="listbox"` + 「更换模型」），断言控件可见且仍归位到工具栏，并验证「生成标题」点击后经主进程写回与回显。

## 使用说明

- 下载 Windows x64 安装包；安装前请先从托盘退出旧版 Pi Web Box。
- 更新后无需重新切换 pi-web 界面语言，也无需执行 `/reload`；若 Box 已打开，重启一次 Box 即可加载新注入脚本。
