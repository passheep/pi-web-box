# Pi Web Box v0.7.7

本版本修复「生成标题」与「提示词增强」在 reasoning 模型下把输入当成普通提问、直接采用助手应答的问题。

## 修复

- **生成标题**：标题语料改为「会话最初目标 → 用户消息（按时间顺序）→ 少量助手进展（仅供参考）」，并读取 pi-web 接口提供的 `info.firstMessage`，不再让尾部的交付回复占据大部分上下文。提示词明确要求概括整场会话的核心任务或交付物，禁止复述、截断或拼接助手回复，禁止「好的 / 已修复 / 交付摘要 / 后续动作 / 需要我…吗」等对话式措辞。
- **提示词增强**：强化原有提示词，明确输入框草稿是待编辑的数据、不是向模型提出的问题；把草稿包成显式 JSON 数据发送，要求输出仍然是「用户向开发助手下达的指令」。模型若仍以助手口吻回答、给出修复方案或向用户提问，会带反馈重试一次；两次都不合格则明确提示「未采用结果」，绝不把 AI 回答写回输入框。
- **两条链路共用输出校验**：拒绝被长度上限截断的输出、工具调用和空正文；标题还会检查是否像助手应答、是否长段照抄会话原文，并把 `maxTokens` 降到 256。Box 的「生成标题」按钮与内置的 `pi-session-name` 扩展使用同一套提示词、取样和校验规则，自动命名、手动重命名和按钮生成三条入口一致。
- Box 设置的「会话命名」安装状态现在会识别扩展版本 `1.2.0`；升级后需要重新安装一次内置扩展（或在 pi 中执行 `/reload`），才能加载新的自动命名逻辑。

## 验证

- TypeScript 类型检查通过；151 项 Box 单元测试、15 项 `pi-session-name` 扩展测试全部通过。
- 新增回归覆盖：中文/繁中/回答式/照抄式坏标题被拒绝且不写回会话名；重试后合格标题写回；提示词增强不采用「标题插件的问题在于…需要我直接改代码吗」这类回答，并拒绝截断输出与工具调用；取样时首条用户目标置顶、尾部助手进展限量。

## 使用说明

- 下载 Windows x64 安装包；安装前请先从托盘退出旧版 Pi Web Box。
- 更新后在「Box 设置 → 会话命名」重新安装内置扩展，或到 pi 里执行一次 `/reload`；之后新建会话即可验证自动命名。
- 本版本仅由离线单元测试与扩展测试验证，真实模型效果请按实际使用场景测试。
