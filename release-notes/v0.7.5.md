# Pi Web Box v0.7.5

本版本修复设置窗口「会话命名」面板内容被截断、命名模型切换后不生效的问题，并在 Pi Web 输入框旁新增「生成标题」按钮。

## 新增

- **Pi Web 输入框旁新增「生成标题」**：位于「增强」按钮右侧，点击后由 Box 读取当前会话的对话内容，用「会话命名」里选定的模型重新生成标题，并写回会话名（`YYYYMMDD-标题`，与自动命名格式一致）。整个流程走 pi-web 自己的接口（读会话 + 改会话名），**不依赖插件是否为最新版本**，因此点击即可用；生成中、成功与失败都会在按钮旁浮出提示，失败原因直接显示（例如未配置模型、HTTP 401）。未选择命名模型时仍可点击，会提示先到「Box 设置 → 会话命名」里选模型。

## 修复与优化

- **修复「Box 设置 → 会话命名」面板放不下、内容被截断**：面板内容改为独立滚动区，底部「保存」按钮固定在面板底部，滚到底即可看到全部开关、模型选择、插件状态与说明文字；「Pi 配置」面板同样处理。
- **修复切换命名模型后 `/session-name rename` 不生效**：插件是 pi 进程里已经加载的代码，覆盖文件后必须重载才会用新代码。现在「会话命名」面板新增「安装或更新后需要重载」说明，安装/更新的结果提示也明确写出「在 pi 中执行 `/reload` 后生效」。只改开关与模型不需要重载，保存后即刻生效。
- 提示词增强与「生成标题」共用同一套模型调用（请求参数、超时与错误文案），减少重复实现。

## 使用说明

- 下载 Windows x64 安装包；安装前请先从托盘退出旧版 Pi Web Box。
- 更新过插件（或在旧版 Box 里装过插件）后，请在 pi 的输入框里发送一次 `/reload`，让新版本插件生效；「生成标题」按钮不受此限制。
- 命名与生成标题使用「Box 设置 → 会话命名」里的模型，请选一个 `models.json` 中真实存在、且已配置 API Key 的模型。
