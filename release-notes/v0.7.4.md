# Pi Web Box v0.7.4

本版本让标题栏与设置窗口真正跟随 Pi Web 的任意主题，新增启动前的环境自检、Pi 配置面板与会话命名集成，并修复首个标签不显示会话名的问题。

## 新增

- **主题自动实时跟随**：标题栏、标签栏与设置/统计窗口的颜色改为直接读取 Pi Web 页面的 CSS 变量（`--bg`、`--bg-panel`、`--border`、`--text`、`--text-muted`、`--accent`），切换主题立即生效。pi-web 0.12 新增的暖沙、岩蓝、暮紫、丁香、余烬、高对比浅色/深色、Zenburn 全部支持，以后 pi-web 再加主题也无需改 Box 也能跟随；页面读不到颜色时回退到内置色板。
- **启动环境自检**：启动时先检测 Node.js / npm。缺少 npm 时不进入主界面，直接给出「下载 Node.js」与「重试」入口；检测到缺少 pi 或 pi-web 时提示选择「一键安装」或「关闭并退出」，一键安装过程在启动页显示 npm 输出与进度，装完自动继续。设置里手动指定过命令路径的组件不参与「缺失」判定。可用 `PI_WEB_BOX_SKIP_ENV_CHECK=1` 跳过自检。
- **Box 设置新增「Pi 配置」**：显示 pi 的本地目录（`~/.pi/agent`）与全局 `AGENTS.md`，可一键打开文件夹或文件；`AGENTS.md` 不存在时可点「新建」写入空白模板（文件没有默认关联程序时自动改为在文件管理器中定位）。
- **Box 设置新增「会话命名」**：为 `pi-session-name` 插件提供「启用自动命名」开关与命名模型（供应商 + 模型）选择，保存后写入 `~/.pi/agent/pi-session-name.json`，插件每次命名前重新读取，**改完即刻生效、无需重启 pi**；本地没有该插件时可一键安装或更新，更新会连同插件自带的测试文件一起同步。

## 修复与优化

- 修复首个标签一直显示「新标签页」的问题。根因是 pi-web 首屏自动打开上次会话时不改写 URL（仍是 `/`），而 Box 只从 `?session=` 读取会话；现在页面捕获会旁听 pi-web 为当前会话建立的事件流（`/api/agent/<id>/events`）补齐归属，标签随即显示正确的会话名，切走再回到新建会话页也会正确清空。URL 上的 `?session=` 仍然优先，消息中心与托盘的会话跳转不受影响。
- 移除「Box 设置 → 外观与行为 → 刷新标题栏外观」：主题已实时同步，不再需要手动刷新入口。
- `pi-session-name` 插件不再把命名模型写死；原先硬编码的供应商与模型仍作为默认配置，配置文件缺失或损坏时行为与旧版一致。
- 内置扩展（用量记录 / 会话命名）的检测与安装接口统一，未知扩展名一律拒绝。

## 使用说明

- 下载 Windows x64 安装包；安装前请先从托盘退出旧版 Pi Web Box。
- 会话命名需要在「Box 设置 → 会话命名」里选一个已配置 API Key 的模型；未选模型时自动命名不会执行（手动 `/session-name rename` 仍可用）。
- 排查命名问题可查看 `~/.pi/agent/pi-session-name.log`；排查启动问题可查看设置窗口与故障页中的日志路径。
