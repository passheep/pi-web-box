# Pi Web Box v0.7.2

本版本汇总 v0.6.2 之后经过本地测试的多标签与消息中心功能，以及安装试用期间的修复。

## 新增

- 浏览器式多标签：复用同一个 Pi Web 服务，最多 6 个标签，支持拖拽排序、中键关闭和会话名称自动更新。
- 新建按钮紧贴末尾标签，支持 Ctrl+T、Ctrl+W、Ctrl+Tab / Ctrl+Shift+Tab。
- 每个打开的标签随机分配不同颜色，关闭后释放颜色；采用略鲜艳且色相分明的蓝、绿、紫、橙、玫红、青色板。运行中的会话显示环形动画。
- 本地消息中心：右上角入口及未读角标，消息倒序展示，每页 30 条，仅在滚动到底时加载更早消息，支持跳转会话。

## 修复与优化

- 将“没有更早的消息了”移到列表内部最后一条消息之后，随内容滚动，不再固定占据面板底部。
- 会话名称和运行状态改由主进程独立连接集中查询，避免六条 SSE 占满浏览器同源连接后标签名称无法更新。
- 最小化时跳过 Windows 临时归零的窗口尺寸，恢复时补布局，避免误触发 Pi Web 窄屏逻辑而收起侧栏。
- 修正标题栏顶部空隙与窗口按钮对齐。
- 消息按事件标识去重，查询失败可重试；保留主题同步、托盘、设置、用量统计及提示词增强功能。

## 验证

- TypeScript 构建与 88 项单元测试通过。
- 真实 Electron 六标签回归：名称、颜色、排序、中键关闭、运行状态、SSE 采集及普通/最大化窗口最小化恢复。
- 真实 Electron 消息分页回归：75 条记录按 30/30/15 加载，倒序无遗漏无重复；75/25 条列表的结束提示仅在滚到末尾时可见。

## 使用说明

- 下载 Windows x64 安装包；安装前请从托盘退出旧版。
- 消息库位于 `%APPDATA%/Pi Web Box/notifications.sqlite`，可能包含插件提示及业务内容，请妥善保管。
- 仅保存 Box 页面实际收到的通知，不补录 Box 关闭或连接中断期间的消息；页面提示采集适配 Pi Web 0.9.1。
- 标签关闭仅关闭页面，不主动中止后台会话。
